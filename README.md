A travel poster for Velmara, an island that does not exist: a floating
island with a lighthouse and a waterfall, a low golden sun on a
violet-amber dusk sky, and a teal sea carrying the sun's glittering path.
Drawn entirely in pure Python stdlib — no image files, no network, no
third-party packages. The place name VELMARA is set into the picture in
large cream capitals.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, under 1 MiB).
